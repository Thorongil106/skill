# 簡牘綴合技能包

解壓後，把 `slip-join-discovery` 和 `slip-join-plate` 兩個資料夾放進使用中助手的技能目錄，讓各自的 `SKILL.md` 位於該資料夾的第一層。也可以把解壓的資料夾交給支援本機讀寫的助手協助安裝。兩項技能可分開使用。

| 要做的事 | 使用的技能 |
| --- | --- |
| 手上有一片，想找可能的接片 | [方案探索 1.7.0](slip-join-discovery/README.md) |
| 已知道要拼哪兩片，想做綴合圖或修訂接口 | [圖版核驗 1.8.0](slip-join-plate/README.md) |

**第一次使用**，提供自己能讀取的圖版、釋文、形制尺寸表或已有卡庫。可以直接說「這是我的資料夾，請先說明能建哪些資料卡，再幫我找這支簡的下接片」。只有兩張圖時，也可以說「第一片在上、第二片在下，請用綜合核驗試拼」。助手會按本次來源建立或接入資料卡，告知已有材料和缺項。

**換電腦繼續同一題**，另行搬移你有權攜帶的研究目錄，保留來源、卡庫、任務記錄和配置的相對位置。若原書另存外接碟，把新位置告訴助手，以檔案內容校驗重綁。另一次拍攝或清晰度不同的截圖獨立登記，再定位接口。單純把此技能包分享給同學，同學使用自己的研究檔案即可。

**執行環境**。卡庫檢索工具可使用 Python 3.10 以上的標準函式庫。製作綴合圖需要 Node.js 20.9 以上及 sharp，從 PDF 提取原圖另用 Python、Pillow 和 pypdf。助手先檢查當前設備，依需要接入工具。只用現有圖片製圖可略過 PDF 與 OCR 工具。兩項技能預設可按題目需要查公開資料，要求本輪離線時沿用本輪限制。
