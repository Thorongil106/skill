# 簡牘圖版綴合 · Slip Join Plate

一個協助製作簡牘綴合圖版的AI助手技能（skill）。可直接使用圖片，也可根據簡號在使用者提供的PDF中定位圖版、提取原圖，再以等比縮放、整片旋轉和平移進行試綴，輸出PNG及可編輯SVG。

**保留原圖，讓每一步綴合可以核對、追溯與修訂。** 本技能不使用生成式模型重畫簡面，不補寫古文字，不為追求接口密合而改造斷口。

## 適用情境

- 將兩張簡牘圖像試綴為一張完整圖版。
- 根據簡號，從自己的PDF書庫查找並提取圖版。
- 為某片尋找未知接片，按釋文、形制與物質信息篩選，再核對原圖。
- 比較內輪廓接合、斷面覆蓋或薄削衣的疊壓位置。
- 結合接口形狀、兩側方向、殘字與字距，修訂已有試綴。
- 製作包含完整圖與接口放大圖的研究、討論或教學材料。

圖版試綴是輔助研究的圖像處理結果；圖像看似接合，不代表實物綴合已獲證實。

普通核驗和綜合核驗都會列出各片釋文、試綴後的合讀及簡短文意評估，供人工判斷。原釋、疑讀及來源分開標示；沒有可靠釋文時明示缺項，不為連文補造文字。

## 快速開始

### 1. 載入技能

解壓分享包，保留 `slip-join-plate/` 的完整目錄結構，讓支援技能、文件讀寫與程式執行的助手安裝或載入其中的 `SKILL.md`。

這不是獨立桌面程式。僅有聊天功能、不能讀取文件或執行工具的環境，可以參考判讀流程，但無法完成整套自動提取與出圖。

### 2. 提供圖片或PDF

直接附上兩張圖片，例如：

> 使用簡牘圖版綴合技能，綴合這兩張圖。第一張在上，第二張在下，請保留原始接口輪廓，並核對兩側方向與字距。

也可以提供自己的原書PDF及簡號：

> 將這份PDF登記為我的圖版來源，查找Ⅱ90DXT0216①:34與Ⅱ90DXT0215S:498，提取原圖後試綴，34在上、498在下。

懸泉漢簡預設優先查找紅外線圖版；其他圖版來源依使用者指定與原書實際內容處理。首次沒有來源書籍時，須先提供PDF或圖片，僅憑簡號不能取得未提供的原書。

### 3. 選擇核驗範圍與畫質處理

每一組實際試拼前，助手會先問：**「是否需要进行综合核验？」** 普通模式也提供釋文與文意參考；綜合模式另外查雙版、木紋、出土背景、材質、形制尺寸等。如果你在這次要求中已明確選好，就不用再答一次；同組續作與修訂沿用本組答覆，下一組重新確認。

若待接片的清晰度明顯不一致，助手會指出哪片接口或殘筆難以辨認，再問是否繼續。你可選擇有限試拼、先查較清楚來源或暫緩。畫質差不會被當成不可綴合，也不會靠改形、銳化或生成式修復強求密合。未答時可先核來源與釋文，實際試拼等待答覆。詳見 [試拼前確認與畫質預檢](references/preflight.md)。

### 4. 內部核驗後再交你複核

助手先自行檢查原圖邊界、灰底白邊、局部覆蓋、兩側、字距及適用的雙版接續，發現能由現有資料解決的問題先修正，再交採用圖。若仍有關鍵疑點，會指出具體位置及其對判斷的影響，減少反覆要求你檢查整張圖的負擔。使用者要求逐組複核時仍會逐組等待。

需要你複核接口時，會提供**8–12個具名錨點**的總覽圖，用「P05—P07」等編號指出待核段，並附無標線原圖。修訂保留編號，未定點／段明確標出；不需要你逐點重新審查。

可直接指出具體位置或判斷，例如：

> 上片接口自左至右第二個凹口應沿內輪廓；下片上端的殘筆與上片末端殘字分屬兩字，請同時核對字距。

助手應保存已接受的糾正，重新核對相關假設，再輸出修訂版。說「繼續未完成的工作」時，會先讀本組的當前版本與待核事項，重用已定位的原圖，不從頭反覆檢索。

### 尋找未知接片

也可以提出有範圍的檢索要求，例如：

> 為這支殘觚找下接片，先查同探方，限定原書標注殘觚或削衣者；下片釋文可能以「敢言之」「言之」「敢」或「言」起首。請啟用綜合核驗，同探方沒有合適者再擴大範圍。

這類任務先確定本題的形制邊界和出土範圍，再按接口釋文、材種及上殘／下殘等描述縮小範圍，對照書寫與彩版木紋；有具體支持才進入摳邊和接口試排。同探方只是優先順序，除非明確限定，並非硬性排除條件。「殘觚或削衣」等限制只適用於提出該要求的任務。

明顯不合者會撤出，資料不足者會列待核；不為交付拼圖而強行接合。未找到方案時，交付已查範圍、排除理由和缺項，並保留檢索記錄供續作重用。這不等於證明原書中沒有可綴片，也不承諾自動找出綴合方案。詳見 [候選檢索與篩選](references/candidate-search.md)。

### 可選：啟用綜合核驗

**由你在每組試拼前選擇。** 彩色／紅外雙版、木紋、物質信息及尺寸的整套核查可選；釋文與文意參考兩種模式都提供。需要更完整地檢驗候選方案時，也可以直接說：

> 啟用綜合核驗：彩色與紅外圖版都進行綴合，綜合對比木紋，並結合形制尺寸及綴合後的釋文文意評估可行性。

啟用後，助手先從原書及未拼接原圖核對形制、材種、殘缺方向、筆畫粗細、墨色與書風，木紋主要看彩色圖版，紅外主要補看墨跡。有具體支持的候選才製作彩色與紅外兩組綴合圖，聯合比較出土背景、接口同字復原及跨縫木紋接續；核對原書的長寬厚與接後長度相容性，區分殘長合計與全長；再列出原釋文、疑讀及綴合後的暫擬文字接續，附簡短綜合意見。兩種成像的尺度與拍攝差異須另行核對，不能直接複製像素位置；會記錄同片跨成像校準的誤差，不把配準分數當綴合成功率。接口原釋及已有尺寸記錄的疑點先查出，再進行精細試排；不要求每個文字命中者先查齊尺寸，兩片接後仍殘也不因此排除。

接口殘筆能復原同一字，是直接的形態接續證據，與文意通順分開評估。厚度數值不同不會自動否決，會如實記錄差異、測量口徑及其影響；同探方、材質、書風與形制的共同支持也會納入。證據足夠時可作「當可綴合」的研究判斷，並另記圖版是否已準確呈現該方案。

彩版與紅外的接口顯示可能因原有圖像處理而不同。核驗時會先排除誤裁和錯位，再逐段優先參考邊緣更精確清楚的一版，讓另一版補充木紋、斷面或墨跡信息；不要求兩版輪廓完全重合，也不固定認定紅外總是較準。

**文意僅作參考。** 字跡不清、缺字或釋讀未定造成文意無法連接，不作否定綴合的依據；文意通順也不能單獨證明綴合。資料缺失會明示「未能核驗」，不補造資料。只要求雙版出圖或單查尺寸時，按指定範圍處理，不自動擴大為整套核驗。

詳見 [綜合核驗流程](references/integrated-verification.md)。

## 核心工作流程

1. **恢復任務並分流**：確認完整簡號、面別、次序與已接受判斷；未知接片先篩候選，原刊既綴圖可作觀察參照。
2. **準備來源並確認選擇**：核原頁、原生圖與釋文；詢問本組模式，發現明顯畫質差異再詢問是否繼續。
3. **獨立辨邊與分區**：各片分辨外輪廓、簡面內界、可覆蓋斷面、保留面與不確定區；先記同字／異字和逐段誰覆誰。
4. **有依據地試排**：尺度、長段側緣、近接口地標及字距共同定位置，另留未用於定位的線索驗收。
5. **內部診斷與修正**：分清位置、材料分區、背景蒙版三類問題；改什麼就重查受影響的視圖，先解決白邊、錯位和誤遮。
6. **交付採用圖與具體疑點**：列各片原釋、合讀、文意參考和來源；雙版分別標狀態。人工主要處理內部仍無法解決的關鍵疑點，診斷圖和修訂記錄可回查。

參見 [交付前內部核驗](references/internal-review.md)。技能會利用既綴圖和人工修訂作 [案例學習](references/learning-from-joins.md)，將觀察轉成下一輪操作；不把某一案例的倍率、位移或覆蓋方向套到其他簡。

### 判讀原則

- **外輪廓不一定是接合線。** 部分接口位於簡面內輪廓，需逐段判斷。
- **接口通常用8–12個關鍵錨點分段核查。** 優先標端點、凹口、台階與色界轉折，再逐段貼原圖追蹤；細密輪廓可有更多頂點，複雜處可加密。各段都看邊界兩側的材料性質，不靠插值加點或平滑線冒充精準；由助手先內審，不要求你逐點批准。
- **淺白或無墨不等於可刪除。** 它可能是須保留的簡面、接口平面或淡纖維。
- **斷面覆蓋須有依據。** 厚度可見的殘簡與薄削衣採不同判讀方式；同一接口可分區交替覆蓋，各分區仍共用同一整片位置。
- **殘筆靠近不等於同字。** 異字須保留合理字位；少量殘墨的中心不能直接當完整字心。
- **區分待核與已排除。** 有試排依據但更近會遮墨時，保存少量方案及具體疑點；已確認材質、形制或書寫不合，或使用者明確撤回時，停止試拼並同步撤回現行圖說。不能以曝光、測量誤差等未證實假說替衝突辯解。
- **密合不能犧牲整體關係。** 不為局部貼合扭斜兩片、壓縮字距或改裁輪廓；單次試排出現空隙也不足以證明不可綴合。

## 輸出內容

以下圖版用於已進入試排且未被排除的方案。未知接片檢索還會保存候選表及狀態；沒有候選通過篩選時，只交付檢索與核驗記錄，不強制生成PNG／SVG。

| 文件 | 用途 |
| --- | --- |
| 完整PNG | 白底綴合圖版 |
| 接口局部PNG | 放大觀察接縫；涉及字距時包含近鄰字 |
| SVG | 內嵌來源圖像，保留可編輯蒙版與整片變換 |
| 原圖輪廓核查圖 | 核對裁切是否遺漏材料或墨跡 |
| 灰底全圖／接口圖層核查圖 | 暴露外背景白邊，接口並列合成與各顯示圖層；供內部核驗，不能自動判定材料 |
| 反向圖層對照 | 有疊壓時輔助檢查遮擋 |
| JSON參數與來源記錄 | 保存變換、來源SHA-256及定位資訊 |
| 判斷記錄 | 記錄採用依據、用戶糾正及尚未解決的問題 |

PNG在縮放或旋轉時會重採樣；「保留原圖」指不重繪、不補筆，並保留可核對的來源資料。放大不會增加原圖本來沒有的細節。

## 環境需求

| 工作 | 所需能力 |
| --- | --- |
| 圖片拼接與PNG／SVG輸出 | Node.js 20.9以上、sharp |
| 掃描PDF原圖提取 | Python 3.10以上、pypdf、Pillow |
| PDF頁渲染 | PyMuPDF或Poppler；macOS可選PDFKit助手 |
| 印刷簡號OCR | Tesseract及語言資料；macOS可選Vision |

OCR是可選能力，缺少OCR不影響直接使用圖片綴合，也可透過文字層或目視核對簡號。OCR候選須回到原頁確認。

助手應先重用現有依賴。需要另行安裝時，可在技能目錄或隔離環境中執行：

```sh
python -m pip install -r requirements.txt
npm install --omit=dev
```

環境檢查與基本命令如下；命令中的腳本位置須依實際技能目錄調整，任務資料建議另存：

```sh
python scripts/check_environment.py
python scripts/pdf_library.py register --id my-volume --pdf "books/volume.pdf" --title "我的圖版來源" --kind infrared
python scripts/pdf_library.py search --slip "Ⅱ90DXT0216①:34"
node scripts/compose.cjs --config job.json --out-dir output
```

登記PDF不等於完成全書索引；助手仍須逐步定位、核號。一般使用者可以直接提出綴合要求，由助手準備配置和執行命令。

## 跨設備與分享

技能包不包含作者的書籍、圖片、個人書目庫或私人路徑。每位使用者提供自己的來源，在自己的任務目錄建立登記與快取。

新任務優先使用相對路徑，整個任務目錄一起搬遷即可保留文件關係。PDF另存到新位置時，可以重新綁定：

```sh
python scripts/pdf_library.py relink --pdf-id my-volume --pdf "books/new-location.pdf"
```

只有內容SHA-256相同的PDF才能沿用原定位；不同掃描本須重新登記並核頁。既有絕對路徑仍相容，但失效時須核對來源後更新。

分享技能時，請排除原書、裁圖、書目庫、快取、任務配置、運行記錄、內嵌原圖的成果SVG，以及本機安裝的依賴目錄。成果與運行記錄可能包含原圖或本機路徑，應與通用技能包分開處理。

## 已驗證範圍與限制

可移植版已在macOS環境驗證圖像拼接、相對路徑任務搬遷、來源重新綁定、中文與空格路徑、Poppler渲染及OCR輸出解析。Windows／Linux按通用路徑和工具接口適配，尚未實機測試；OCR解析測試不代表實際識別準確率驗證。

綜合核驗流程已在一組原書彩色／紅外圖版上實際走通，並核對尺寸表與接口原釋；後續已依使用者補充的研究判斷修訂評估流程，將研究結論與圖版呈現狀態分開記錄。這只驗證了出圖、來源追溯與矛盾記錄流程，並不代表識別準確率或自動判綴能力已獲驗證。

1.5.0整合多輪內輪廓、交替覆蓋、異字排距、雙版錯位及白邊修訂經驗：新增試拼前詢問、畫質差異選擇、內部核驗及修訂後重驗；工具新增灰底／獨立圖層診斷，以及可選的同片分區來源與變換一致性檢查。候選檢索、來源可移植和釋文交付沿用。這些改進可減少可預防的處理錯誤，未提供自動辨邊或識字模型，也不宣稱已測得判綴準確率。

1.5.1加入8–12個有依據的接口關鍵錨點及逐段核查，區分具名錨點、細密描線頂點和整片對齊地標；需要人工複核接口時提供8–12個具名錨點的總覽圖，以固定編號定位疑點。不把點數增長換算為準確率提升。此輪更新判讀與展示流程，出圖工具與既有圖版未改。

接口判讀、殘字歸屬與覆蓋範圍仍需依原圖分析及人工核對。工具不會自動證明兩支簡必然可綴，也不會為得到無縫效果生成缺失材料。
