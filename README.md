# 簡牘圖版綴合 · Slip Join Plate

一個協助製作簡牘綴合圖版的AI助手技能（skill）。可直接使用圖片，也可根據簡號在使用者提供的PDF中定位圖版、提取原圖，再以等比縮放、整片旋轉和平移進行試綴，輸出PNG及可編輯SVG。

**保留原圖，讓每一步綴合可以核對、追溯與修訂。** 本技能不使用生成式模型重畫簡面，不補寫古文字，不為追求接口密合而改造斷口。

## 適用情境

- 將兩張簡牘圖像試綴為一張完整圖版。
- 根據簡號，從自己的PDF書庫查找並提取圖版。
- 比較內輪廓接合、斷面覆蓋或薄削衣的疊壓位置。
- 結合接口形狀、兩側方向、殘字與字距，修訂已有試綴。
- 製作包含完整圖與接口放大圖的研究、討論或教學材料。

圖版試綴是輔助研究的圖像處理結果；圖像看似接合，不代表實物綴合已獲證實。

## 快速開始

### 1. 載入技能

解壓分享包，保留 `slip-join-plate/` 的完整目錄結構，讓支援技能、文件讀寫與程式執行的助手安裝或載入其中的 `SKILL.md`。

這不是獨立桌面程式。僅有聊天功能、不能讀取文件或執行工具的環境，可以參考判讀流程，但無法完成整套自動提取與出圖。

### 2. 提供圖片或PDF

直接附上兩張圖片，例如：

> 使用簡牘圖版綴合技能，綴合這兩張圖。第一張在上，第二張在下，請保留原始接口輪廓，並核對兩側方向與字距。

也可以提供自己的原書PDF及簡號：

> 將這份PDF登記為我的圖版來源，查找Ⅱ90DXT0216①:34與Ⅱ90DXT0215S:498，提取原圖後試綴，34在上、498在下。

懸泉漢簡預設優先查找紅外線圖版；其他圖版來源依使用者指定與原書實際內容處理。首次沒有來源書籍時，須先提供PDF或圖片，僅憑簡號不能取得未提供的原書。

### 3. 核對與修訂

可直接指出具體位置或判斷，例如：

> 上片接口自左至右第二個凹口應沿內輪廓；下片上端的殘筆與上片末端殘字分屬兩字，請同時核對字距。

助手應保存已接受的糾正，重新核對相關假設，再輸出修訂版。

## 核心工作流程

1. **核對來源與次序**：確認完整簡號、面別、上下／左右排列，以及已接受的局部判斷。
2. **提取原圖**：核對原頁標籤，記錄書頁、PDF頁、裁圖座標及來源校驗值。
3. **獨立辨邊**：區分外輪廓、推定接口線、可覆蓋斷面、須保留簡面與不確定區。
4. **建立對齊依據**：檢查尺度、兩側方向、殘筆歸屬及近鄰字距。
5. **綜合試排**：每個候選位置共同檢查接口、兩側接續、文字與遮擋。
6. **核驗並交付**：查看全圖、接口局部、原圖輪廓對照及必要的反向疊層圖，保存參數和判斷記錄。

### 判讀原則

- **外輪廓不一定是接合線。** 部分接口位於簡面內輪廓，需逐段判斷。
- **淺白或無墨不等於可刪除。** 它可能是須保留的簡面、接口平面或淡纖維。
- **斷面覆蓋須有依據。** 厚度可見的殘簡與薄削衣採不同判讀方式，不預設下片一定覆在上片之前。
- **殘筆靠近不等於同字。** 異字須保留合理字位；少量殘墨的中心不能直接當完整字心。
- **密合不能犧牲整體關係。** 不為局部貼合扭斜兩片、壓縮字距或改裁輪廓；單次試排出現空隙也不足以證明不可綴合。

## 輸出內容

| 文件 | 用途 |
| --- | --- |
| 完整PNG | 白底綴合圖版 |
| 接口局部PNG | 放大觀察接縫；涉及字距時包含近鄰字 |
| SVG | 內嵌來源圖像，保留可編輯蒙版與整片變換 |
| 原圖輪廓核查圖 | 核對裁切是否遺漏材料或墨跡 |
| 反向圖層對照 | 有疊壓時輔助檢查遮擋 |
| JSON參數與來源記錄 | 保存變換、來源SHA-256及定位資訊 |
| 判斷記錄 | 記錄採用依據、用戶糾正及尚未解決的問題 |

PNG在縮放或旋轉時會重採樣；「保留原圖」指不重繪、不補筆，並保留可核對的來源資料。放大不會增加原圖本來沒有的細節。

## 環境需求

| 工作 | 所需能力 |
| --- | --- |
| 圖片拼接與PNG／SVG輸出 | Node.js 20.9以上、sharp |
| 掃描PDF原圖提取 | Python 3.10以上、pypdf、Pillow |
| PDF頁渲染 | PyMuPDF或Poppler；macOS可選PDFKit助手 |
| 印刷簡號OCR | Tesseract及語言資料；macOS可選Vision |

OCR是可選能力，缺少OCR不影響直接使用圖片綴合，也可透過文字層或目視核對簡號。OCR候選須回到原頁確認。

助手應先重用現有依賴。需要另行安裝時，可在技能目錄或隔離環境中執行：

```sh
python -m pip install -r requirements.txt
npm install --omit=dev
```

環境檢查與基本命令如下；命令中的腳本位置須依實際技能目錄調整，任務資料建議另存：

```sh
python scripts/check_environment.py
python scripts/pdf_library.py register --id my-volume --pdf "books/volume.pdf" --title "我的圖版來源" --kind infrared
python scripts/pdf_library.py search --slip "Ⅱ90DXT0216①:34"
node scripts/compose.cjs --config job.json --out-dir output
```

登記PDF不等於完成全書索引；助手仍須逐步定位、核號。一般使用者可以直接提出綴合要求，由助手準備配置和執行命令。

## 跨設備與分享

技能包不包含作者的書籍、圖片、個人書目庫或私人路徑。每位使用者提供自己的來源，在自己的任務目錄建立登記與快取。

新任務優先使用相對路徑，整個任務目錄一起搬遷即可保留文件關係。PDF另存到新位置時，可以重新綁定：

```sh
python scripts/pdf_library.py relink --pdf-id my-volume --pdf "books/new-location.pdf"
```

只有內容SHA-256相同的PDF才能沿用原定位；不同掃描本須重新登記並核頁。既有絕對路徑仍相容，但失效時須核對來源後更新。

分享技能時，請排除原書、裁圖、書目庫、快取、任務配置、運行記錄、內嵌原圖的成果SVG，以及本機安裝的依賴目錄。成果與運行記錄可能包含原圖或本機路徑，應與通用技能包分開處理。

## 已驗證範圍與限制

可移植版已在macOS環境驗證圖像拼接、相對路徑任務搬遷、來源重新綁定、中文與空格路徑、Poppler渲染及OCR輸出解析。Windows／Linux按通用路徑和工具接口適配，尚未實機測試；OCR解析測試不代表實際識別準確率驗證。

接口判讀、殘字歸屬與覆蓋範圍仍需依原圖分析及人工核對。工具不會自動證明兩支簡必然可綴，也不會為得到無縫效果生成缺失材料。
