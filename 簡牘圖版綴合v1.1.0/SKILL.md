# 簡牘綴合圖版

本技能製作**原圖的幾何拼接**。調用本技能表示採用以下純裁切與貼圖流程；不要將原始學術圖版送入生成式圖像模型。生成式模型可能重畫墨跡、木紋或茬口，即使要求「保持原樣」亦不適用。

本技能不附帶書籍或個人書目庫。首次在新設備使用、缺少來源或工具、搬遷既有任務時，先讀 [跨設備使用與來源綁定](references/portable-setup.md)。來源取自當前使用者提供的圖像、PDF或已授權來源；不要尋找技能作者的私人路徑。

## 工作原則

- 原檔不改動。SVG嵌入來源圖片，輪廓蒙版與位置參數分開保存；輸出可逆、可追查。
- 保留字跡、殘筆、污漬與木紋。只移除簡面外的背景；不可把簡面內的白色當背景刪掉。
- 只允許等比縮放、整片旋轉與平移。不得鏡像、拉伸、透視矯正、局部變形或補畫，使茬口看似吻合。
- 不能為了吻合而改裁茬口。每片輪廓須分別據自身原圖描出；保留真實缺口和不吻合處。
- 外輪廓、簡面內輪廓與厚度斷面分開判讀。推定接口線不等於裁切線；淡白區也可能是須保留的簡面。覆蓋須有局部依據，不能只為消除白縫。
- 每個候選位置共同核對接口形狀、兩側方向與寬度、墨跡及字距。不得只追求輪廓密合，也不得只依字距判定實物不能接合。
- 拼接圖是圖像處理結果。是否實物綴合、文字如何復原是另一項研究判斷；使用者未要求時不附加長篇考證。

## 處理流程

1. **核對輸入與已接受的糾正。** 記下本組簡號、上下／左右次序、面別、材料形態及使用者指出的局部，沿用後續仍有效的糾正，不把上一組的斷面處理套到下一組。使用者只給簡號時，先讀工作目錄的 `.slip-join-plate/library.json`，沿用本工作窗口已授權且可讀的PDF，不重複索取路徑、上傳或讀取許可。首次沒有書目庫時，先查本輪附件與已知來源；仍無原書才請使用者提供PDF或兩張圖，不能僅憑簡號取得未提供的書籍。PDF路徑變動時先在已知來源目錄查找並以內容校驗重新綁定。冊次、面別和簡號不足以唯一定位才詢問；無A/B標記的簡號不擅加A。
2. **準備原圖。** 懸泉漢簡預設查找**紅外線圖版**；彩版只在必要時補核形制，不以彩色圖灰階化充作紅外。按 [PDF定位流程](references/pdf-library.md) 查冊次和圖版頁，核對原頁的完整簡號，再提取原始解析度簡面。保存書頁、PDF頁、來源位置和裁圖座標。使用者明確指定截圖時直接處理；只有茬口局部則只作局部拼接。
3. **獨立辨邊與分區。** 各自按原圖描外輪廓，先寬鬆保留淡墨、纖維及淺色簡面。涉及內輪廓、斷面覆蓋、削衣或反覆修訂時，先讀 [接口判讀與綜合試排](references/join-assessment.md)。逐段區分簡面、可覆蓋斷面和不確定區，另標推定接口線。茬口不清時保留寬鬆輪廓或未摳邊對照；如原圖支持修正誤裁，另存蒙版版本與理由，不能反向照另一片裁出互補邊線。
4. **建立對齊依據。** 以實測尺寸或未殘損的簡身寬度估計等比倍率；用兩側較長的保存段檢查方向與寬度接續，不依單個尖角定旋轉。先判斷接口殘筆屬同字、異字或未定；異字須保留合理字位，殘筆的中心或包圍框不直接當完整字的字心。兩側近似平行是接續依據，保留原有彎曲或收分，不強制成直線。
5. **綜合試排。** 在有依據的比例、旋轉、平移與疊層範圍內比較候選；每次同時檢查接口、兩側、字距及遮擋。先辨明可覆蓋區，再決定前後層次；不預設下片必在前。可用至少兩對可辨地標求初始相似變換，三對以上觀察殘差。收到關鍵糾正時重審相應假設和候選範圍，不只沿用錯誤基準反覆挪動幾個像素。各條件衝突時重查來源、邊界與比例，仍未解決則交付有標示的試排或候選比較，不強求無縫。
6. **渲染與核驗。** 使用隨附腳本，查看來源輪廓核查圖、完整拼接圖和接口放大圖；涉及字位時，局部須包含接口前後相鄰字。檢查淡墨有無被裁去、前景是否用背景或簡面遮住應保留的墨跡；有疊壓時查看反向圖層或分離對照。以同倍率、同局部範圍比較修訂，逐項核對已接受的用戶糾正。
7. **交付與續作。** 預設交付白底完整PNG、接口PNG和內嵌原圖的SVG；透明底PNG按需要提供。保留JSON參數、來源SHA-256及本輪判斷記錄。將已淘汰的解釋標為失效，記明當前採用版本，續作不回到舊假設。回覆以簡號、圖片、下載連結及必要的一句處理說明為主；依實際證據稱作「試綴」「排距試圖」或「局部較吻合」，不因圖片看似連成一體宣稱實物綴合已確定。

當使用者說「仿姚磊圖版」，理解為白底、保留原圖、茬口清楚、可並列完整圖及局部。只有灰度圖時不要合成「彩圖」「紅外」版本；若提供兩種成像，分開各拼一組。

## 按簡號調用

例如「拼接Ⅱ90DXT0216②:14＋Ⅱ90DXT0215S:416A，用紅外線圖版」。助手完成PDF檢索、原頁核號、簡面提取、摳邊與拼接；不要求使用者提供頁碼或裁切座標。先查已核定位記錄；新簡號按冊中編排取錨點、縮小頁段並增量OCR。每次找到的頁碼與裁圖位置寫回本地書目庫，供後續重用。尚未索引的頁面仍需檢索，不把局部索引未命中當作原書無此簡。

## 工具與參數

採用本技能的確定性腳本，不使用 imagegen。需要修改工具時保持上述原圖約束。

若環境提供 `load_workspace_dependencies`，先用它取得工具與套件位置；沒有此工具時使用當前環境的Python、Node及已安裝套件，執行 `scripts/check_environment.py` 檢查所需能力。不要將上一台設備的執行檔或套件絕對路徑搬過來。`sharp` 可由任務或技能的依賴目錄載入，也可用 `--sharp-module` 指向現有安裝。依賴清單及可選渲染／OCR工具見 [跨設備指南](references/portable-setup.md)；缺少非必要OCR時可人工核號，不擅自下載原書或安裝工具。

參數格式與指令見 [references/config.md](references/config.md)。由助手建立參數，毋須要求使用者填座標或JSON。

```text
node scripts/compose.cjs --config job.json --out-dir output/slip-join
```

腳本會保存來源圖的完整嵌入，蒙版不刪除SVG中的原始圖像資料。PNG因縮放或旋轉可能發生重採樣；「保留原圖」指不重繪、不補筆，不宣稱變換後逐像素完全不變。放大僅供觀察，不稱作新增細節或提高清晰度。

## 驗收重點

- 簡號、面別與拼接順序符合使用者指定。
- 原圖核查圖上的輪廓沒有切斷應保留的墨跡；來源圖未被重寫。
- 疊壓區域已檢視，沒有用後貼片的背景蓋住先貼片的字跡；不能排除時提供分離／透明對照，不稱作無損對接。
- 推定接口線與外輪廓有區別；覆蓋範圍有原圖或使用者局部判斷的依據，未遮去須保留的接口平面。
- 接口形狀、兩側接續、殘字歸屬及字距已共同核對；若仍衝突，交付說明點明未解決的是哪一項。
- 真實缺口、裂縫、尺寸或裁圖限制仍可見，不磨平接縫、不生成補綴。
- 最終PNG與SVG已查看；參數及來源校驗值齊全。
