# 拼接參數

`compose.cjs` 使用 Node.js 與 sharp。所有座標以**來源圖片像素**為單位，左上為原點；角度為度，正值在螢幕座標中順時針。`x,y` 指來源原點變換後的位置。先等比縮放，再旋轉，最後平移。JSON內不支援非等比、鏡像或透視變換。

## 最小範例

```json
{
  "title": "兩簡綴合試拼",
  "name": "join",
  "pixelsPerUnit": 3,
  "margin": 12,
  "background": "#ffffff",
  "pieces": [
    {
      "id": "upper",
      "label": "上片簡號與面別",
      "image": "sources/upper.png",
      "polygon": [[0,0],[100,0],[100,180],[0,180]],
      "transform": {"x": 0,"y": 0,"scale": 1,"rotation": 0}
    },
    {
      "id": "lower",
      "label": "下片簡號與面別",
      "image": "sources/lower.png",
      "polygon": [[0,0],[100,0],[100,200],[0,200]],
      "transform": {"x": 0,"y": 180,"scale": 1,"rotation": 0}
    }
  ],
  "detail": {"x": 0,"y": 160,"width": 100,"height": 40,"pixelsPerUnit": 6},
  "notes": ["記錄順序、比例、斷口判斷及裁圖限制。"]
}
```

`polygon` 可省略，代表保留整張原圖；白底截圖不可因此宣稱已摳出簡面。至少三個點，不得自交、越出原圖範圍，或使輪廓退化。

來源路徑若為相對路徑，依配置JSON所在目錄解析；新任務優先用相對路徑，連同 `sources/` 整個任務目錄搬遷即可重跑。單機既有絕對路徑仍相容。JSON中的跨平台相對路徑使用 `/`；Windows絕對路徑須正常JSON轉義，不能當作其他系統通用路徑。

從PDF提取的裁圖，每片可加 `"provenance":"sources/416A.source.json"`；腳本核對裁圖SHA-256與路徑後，將原書、成像類型、書頁、PDF頁和裁圖座標帶入清單。以 `pdf_library.py crop` 產生此記錄，新記錄內的圖像路徑相對於 `.source.json` 本身，見 [PDF定位流程](pdf-library.md)。舊記錄搬遷時須核對同一圖像的SHA，再更新路徑，不能為通過校驗任意替換來源。

`pixelsPerUnit` 只控制輸出倍率。原圖沒有比例尺或可靠實測資料時，SVG的版面單位不是毫米，不新增實物比例尺。預設自動以各輪廓的變換後範圍加邊距設定畫布，支援旋轉與負座標。

`pieces` 的先後亦為貼圖層次，後者覆於前者之上。腳本會記錄輪廓的疊壓面積；這只是圖像覆蓋指標，不代表兩實物的厚度或斷口吻合程度。輪廓有疊壓時，腳本加出反向圖層對照PNG，檢查有無遮字。

## 判讀與裁切分開保存

`polygon` 是**實際顯示蒙版**，不會自動識別外輪廓、簡面內輪廓或斷面。標準用法以獨立描得的外輪廓作蒙版；推定接口線、可覆蓋區和字距依據按 [接口判讀流程](join-assessment.md) 另存 `join-review.md` 及必要的標註圖。不要把推定接口線直接替換為裁切邊線，也不要在配置中添加未實作的判讀欄位並假定腳本會驗證它們。

需以有依據的局部分區作顯示蒙版時，仍保存原始外輪廓供比較。現有腳本沒有自動分區判讀或保護墨跡的能力；若用同一來源的多個顯示分區組合，分區須有獨立ID、共用完全相同的整片變換和來源記錄，另記其所屬實物，且不可只靠分區版 `source-check` 代替原始外輪廓核查。

`source-check` 的紅線表示配置中的顯示蒙版，不代表經確認的接口或斷面邊界。`reverse-layer-check` 只調換疊層次序，不是透視、透明或物理接合驗證。腳本的疊壓估算有採樣限制；沒有輸出反向圖也不免除對細小尖端或殘筆的目視檢查。需要透明／分離對照時另行製作並標明用途。

修訂配置另存版本；在 `notes` 記錄假設、改動與未解決衝突。涉及字距時，`detail` 的範圍包含接口兩側的相鄰字，而非只截最窄縫隙。不同候選用相同局部座標、輸出倍率與蒙版版本比較。

## 地標輔助對齊

下片可用 `align` 代替手動`transform`，但不可同時填兩者：

```json
{
  "id": "lower",
  "image": "sources/lower.png",
  "align": {
    "to": "upper",
    "fitScale": true,
    "pairs": [
      {"point": [10,10], "target": [12,180]},
      {"point": [90,10], "target": [92,180]},
      {"point": [50,4], "target": [52,174]}
    ]
  }
}
```

`point` 是待移動片的來源座標，`target` 是已排在前面的參考片的來源座標。腳本將參考點先轉成全局座標，再求相似變換。不擬合倍率時設 `fitScale:false, scale:1`；仍可擬合旋轉與平移。

地標必須可在兩張圖上分別辨認；不是任意挑兩點令計算殘差為零。不因零殘差即判定綴合。手工選點的位置誤差、拍攝角度、截圖倍率與斷口缺損都會影響結果。

## 輸出

- `名稱.png`：完整拼接圖，預設白底。
- `名稱-transparent.png`：透明底完整拼接圖。
- `名稱.svg`：內嵌原圖與矢量蒙版，可再編輯。
- `名稱-detail.png`：指定區域茬口放大圖；未指定`detail`不產生。
- `名稱-source-check.png`：原圖並列、紅色輪廓線及簡號。原照片在此圖不裁切，供核查誤切淡墨。
- `名稱-reverse-layer-check.png`：僅有蒙版疊壓時產生，改變貼圖層次的對照圖，不當成最終版。
- `名稱-parameters.json`：實際參數。
- `名稱-manifest.json`：來源路徑、SHA-256、像素尺寸、蒙版、變換、地標殘差及輪廓疊壓量。

腳本保留原始PNG/JPEG作為SVG內嵌資料；其他sharp可讀格式無損轉成PNG供嵌入，並在清單註明轉碼。來源檔一律不變。

PNG及內嵌原圖的SVG可單獨查看；重跑時使用原始相對路徑配置及裁圖／來源記錄。`-parameters.json`、`-manifest.json` 是當次運行的解析結果，可能含本機絕對路徑，不能當作去除個人資料的公開分享包。分享技能時不包含任何任務產物。
