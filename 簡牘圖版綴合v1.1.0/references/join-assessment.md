# 接口判讀與綜合試排

用於內輪廓接合、斷面覆蓋、削衣、殘字或字距不明，以及收到修訂意見後的重新判讀。先在單片原圖上建立依據，再把兩片放到一起；不要讓「能拼得密」反過來決定邊線。

## 1. 固定本組條件

在工作輸出目錄的 `join-review.md` 記下上下／左右次序、面別、材料形態、已接受的局部糾正及仍待定的問題。區分「原圖可見」「使用者判斷」「助手推測」。使用者指定哪片在上就沿用，不因另一種排列更易貼合而調換；疑點寫入試排說明。

描述局部用簡號、方向、從哪邊起數第幾個凹口／轉折及來源座標。例如「上片接口自左至右第二凹口」，不能只記「中部」或「紅線」。顏色僅是圖例，不承載永久語義。使用者糾正某段時，保留其他已確定條件；更換簡號後重新判讀材料與斷面，不能承襲前一組的可覆蓋範圍。

## 2. 分開描外輪廓、接口線與可覆蓋區

| 對象 | 判讀與處理 |
| --- | --- |
| 外輪廓 | 原圖中材料對背景的邊界。各片獨立描，連同淡纖維、殘墨、缺口保存，作為原始外形核查基準。 |
| 簡面內輪廓／推定接口線 | 書寫面與可見厚度斷面的分界，可能只在部分邊段存在。可與外緣重合，也可沿內側轉折；逐段判斷，不將整條線一律內移或一律沿外緣。 |
| 可覆蓋斷面 | 據局部材質紋理、台階、厚度、連續關係及使用者指認判定的區域。它是疊壓假設，須與保留簡面分開記錄；不能由亮度或缺墨單獨判定。 |
| 須保留簡面／接口平面 | 即使呈白色、無墨或位於凹口旁，也不能自動當作背景或可覆蓋厚度。已有墨跡有助於識別簡面，但不要推論所有無墨區都可遮。 |
| 不確定區 | 以虛線／半透明標記並保留原圖；標記表示判斷未定，不是允許刪除。 |

**厚度可見的殘簡：** 上下片均可能只有局部外緣屬斷面；可以用另一片合理覆蓋有依據的厚度區。某段應沿內輪廓，不代表整片均應沿內輪廓摳掉。覆蓋不能延伸到保留簡面與殘筆。

**薄削衣：** 沒有可辨厚度時，以原有接口形狀、長尖與斜邊的疊壓、兩側方向和文字位置試排；不假設一整圈厚斷面再內縮裁切。若圖像支持局部疊壓，仍須核查遮擋，不把「削衣」當作可以任意重疊的許可。

外輪廓蒙版與接口判讀線分存。確定有誤裁時，回單片原圖改蒙版並記錄差異；對比同一批位置候選時，固定所用蒙版版本，避免以改邊線掩飾位置差異。曲折處保留足夠轉折點，但點數多或線條平滑不代表判讀準確。

## 3. 將字距作為獨立核對條件

- 先記同字、異字或未定。殘筆在左右、高低上碰巧接近，不足以判為同字；同字接續還需筆勢、結構及缺損位置支持。使用者明確區分兩字後，撤銷跨片合字假設。
- 異字的字距在調位前就應納入。分別看兩片接口附近可辨的相鄰字，以筆畫上下界、字體大小和書寫節奏估計一個容許範圍；圖版相對比例要先核對。區分字間空白與字心距，不把兩種量混用。
- 不從殘字僅存的一點、兩筆或包圍框直接推出完整字心。記錄可見筆畫的位置，對缺失字形留出可能的空間；無法估計字心時只比較可見筆畫間距並明示限制。
- 字距可以不均勻。優先取近鄰、多個可辨間隔，不將某一對字的距離當固定步長，也不將本次的像素數或「半個字位」寫成下一組規則。兩片附近字距趨勢不同時列為矛盾，不能只挑支持所選位置的一側。
- 局部圖包含接口上、下的近鄰字，讓字距有可見參照；無需猜出所有釋文才可試排。字距排得自然是支持或排除位置的條件之一，不能代替物理接口證據。

## 4. 同時比較位置、方向、尺度與遮擋

1. **比例與軸向基準。** 優先用實測尺寸；否則取簡身保存較好的寬度段、原圖比例資訊作參照，不用削尖端寬度定比例。觀察左右兩側較長的保存段及接縫附近的寬度變化；保留自然彎曲、收分與拍攝誤差。小角度旋轉也須核對全片，不為一處密合把兩片扭斜。
2. **位置候選。** 以可辨的斜邊、轉折或內輪廓建立初始範圍，與文字容許範圍交叉核對。僅試少量有理由的候選；必要時重估橫向位置、倍率或旋轉，不能收到每次糾正都只縱移固定像素。旋轉、比例的修改須有原圖依據，不能為追求無縫任意搜尋。
3. **疊層。** 根據具體斷面和保留簡面決定誰覆蓋誰。下片在前只是可能方案；兩片都有斷面時，單一全片前後次序可能不足。先以反向疊層、分離或標註圖核查；如需分區顯示，只能用單片本身已辨明的分區及同一整片變換，不能把兩片各裁一半製造互補。
4. **逐候選核對。** 用同一倍率、視窗和蒙版版本比較下列各項，記錄具體位置及現象，無須虛構總分或吻合百分比。

| 核對項 | 觀察內容 |
| --- | --- |
| 接口 | 哪些斜邊／轉折較對應，哪些有缺失、空隙或重疊；重疊是否落在已判可覆蓋區。 |
| 兩側 | 接縫前後兩側的方向、寬度與橫向偏移是否相容；局部貼合是否以全片歪斜為代價。 |
| 文字 | 同字／異字假設是否沿用正確；字位、字距與近鄰書寫節奏是否相容。 |
| 遮擋 | 前景的材料或背景是否遮了應保留的簡面、殘筆、纖維；不能只檢查裁切蒙版有無切墨。 |
| 不確定性 | 邊線不清、色差、來源解析度、尺度或字形殘缺如何限制結論。 |

**矛盾時的回查順序：** 先排除簡號／面別／方向錯置、裁框截斷、背景未抠除及內外輪廓混淆，再核對比例、軸向、疊層和文字假設。新證據支持改動哪項就改哪項，不必重做已核實的PDF提取。仍無合理共同解時，交付最有依據的試排或少量候選，指出矛盾；既不為密合壓縮字距，也不只因一次按字距拉開後有空隙就宣布不可綴合。

## 5. 修訂記錄與交付

`join-review.md` 由助手維護，保持簡短即可：

```markdown
本組條件：簡號／次序／材料；用戶已確定的局部判斷。
來源與邊界：來源記錄路徑；外輪廓版本；推定接口、可覆蓋與須保留區；未定處。
文字依據：同字／異字／未定；哪些近鄰間隔可參照；字形殘缺帶來的範圍。
候選比較：參數及其理由；接口／兩側／文字／遮擋的觀察與衝突。
當前採用：輸出與參數檔；尚存問題；被撤銷的舊假設與原因。
```

主拼接配置的 `notes` 寫入採用版本的依據、限制及此記錄的位置。不要讓舊版標題或說明繼續聲稱已被用戶否定的合字、覆蓋或密合。外輪廓改動與位置改動分開記錄；原檔SHA-256及SVG嵌入資料一致，只能證明來源未被改寫，不能單獨證明蒙版沒有改形或疊層沒有遮墨。

對使用者優先呈現採用版完整圖和局部圖；有影響結論的分歧才加對照。連成一體、線條靠近、疊壓面積大，均不等於實物綴合已獲確認。標註局部較吻合或具體仍存的縫隙即可，保留可編輯來源供下一輪核對。
